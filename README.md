# we_logo

The WavingEye brand, as parameters and a build rather than as files.

## Status

Research and proposal stage. Nothing is built yet. The original artwork sits in
`init/` untouched.

## Documents

- **[`docs/asset-audit.md`](docs/asset-audit.md)**: every measurement taken from
  the files in `init/`: the mark's construction ratios, the lockup geometry, the
  contrast figures, the typeface identification, eleven file defects, and the
  recommended changes to the artwork.
- **[`docs/brand-system-proposal.md`](docs/brand-system-proposal.md)**: what the
  industry uses for this, what does not exist, the proposed repository
  architecture, the CI gates, where kagami fits, and the decisions that are
  still open.

## What the audit found, in one paragraph

The mark is already a parametric system: three files, one artwork, ratios that
agree to four decimal places, a square bounding box, and a single construction
rule (every angled cut drops by exactly one third of a stroke width). The
wordmark is Montserrat Medium at +0.05 em tracking, which is free under the SIL
Open Font License. What is missing is a transparent asset, a small-size cut, a
recorded rule, and any way to produce a variant without redrawing it.
